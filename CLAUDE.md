# Syrian Visual Identity Guidelines for Claude Code

This project follows the official Syrian Visual Identity (الهوية البصرية للجمهورية العربية السورية).

## Design System Tokens
- **Forest Green (Primary)**:
  - Base: `#054239`
  - Light: `#428177`
  - Deep: `#002623`
- **Golden Wheat (Accent)**:
  - Base: `#b9a779`
  - Muted: `#988561`
  - Cream: `#edebe0`
- **Deep Umber**: `#6b1f2a`
- **Canvas / Surfaces**: `#fdfbf7` (Light), `#141414` / `#1c1c1c` (Dark)
- **Typography**: 'HayyakumAllah', sans-serif (Weights: 300, 400, 500, 700)

## Constitutional Flag Specifications
- Aspect ratio: Exactly 3:2.
- 3 equal horizontal bands: Green (`#007A3D`), White (`#FFFFFF`), Black (`#000000`).
- 3 Red stars (`#CE1126`), five-pointed, point-up, spaced at 25%, 50%, 75% along the white stripe.

## Best Practices
- Keep designs elegant, cultural, and respectful of Syrian heritage.
- Provide dual Arabic (RTL) and English (LTR) language support.
