# الهوية البصرية - الجمهورية العربية السورية | Syrian Visual Identity

موقع ويب توثيقي وتفاعلي متكامل يُعيد إحياء وحفظ **الهوية البصرية الرسمية للجمهورية العربية السورية** بعد توقف موقعها الرسمي، مدمجاً بكافة الأدوات الرقمية والموارد التصميمية من بوابة **Syrian Zone**.

المشروع مصمم ليكون تطبيق ويب ثابت (Static Web App) فائق السرعة والأناقة، متوافق بنسبة 100% مع النشر المباشر على **GitHub Pages**، ومزود بدعم ثنائي اللغة (العربية بالاتجاه الطبيعي RTL والإنجليزية LTR)، والوضع الليلي/النهاري، مع الحفظ التلقائي لتفضيلات اللغة والمظهر في المتصفح (LocalStorage).

## 🌟 المحتويات والأقسام الرئيسية

### 1. الرئيسية (Home)
- **واجهة بصرية غنية**: تصميم ترحيبي مهيب يجمع بين شعار *"انتماءٌ راسخ يتجاوز الحدود"*، ورمز الختم الوطني المضيء، ونقش زخرفي نجمي دقيق بدقة عالية، وخلفية مائية للنمط التراثي السوري الأصيل.
- **تكامل الأنماط التراثية في الواجهة (UI Heritage Pattern Integration)**:
  - **الترويسة (Header/Navbar)**: نقش التناظر النجمي الدمشقي التراثي كخلفية مائية أنيقة مع شريط زخرفي ذهبي دقيق.
  - **التذييل (Footer)**: دمج النمط الأموي الأخضر الغابي كنسيج مهيب يندمج بسلاسة مع خلفية التذييل الرسمية.
  - **الصفحة الرئيسية (Hero & Seal Card)**: نقش نجمي دائري مائي خلف العناوين الرسمية وبطاقة الختم الوطني.
  - **كافة الصفحات (Global Ambient Pattern)**: خلفية مائية موحدة من النمط السوري التراثي تطفو بأناقة وخفة في أعلى جميع صفحات الموقع.
- **معرض الأنماط والزخارف التراثية (Heritage Patterns)**: استعراض تفاعلي للأنماط الهندسية الأربعة المستوحاة من العمارة الأموية، التناظر النجمي الدمشقي، وتسنيم قلاع حلب.
- **تطبيقات الهوية في الحياة (Real-World Gallery)**: شبكة بصرية متكاملة (Bento Grid) لنماذج الهوية الواقعية (جواز السفر والوثائق الدبلوماسية، الصروح والواجهات الحكومية الرسمية، المراسم والبدلات الدبلوماسية، اللوحات الحضرية وتغليف المنتجات) بدون هوامش ميتة وبصور ملء البطاقة.
- **شريط رموز المحافظات**: عرض مباشر لمعالم المحافظات السورية بتقنية SVG مع روابط سريعة للأدوات.
- **المبادئ الفلسفية للعلامة**: بطاقات معمقة لـ *"سوريا هي القلب"* و*"قصتنا إلى العالم"*.

### 2. قصة الهوية والرسالة (Brand Story)
- **الرؤية والرسالة والتموضع الوطني**: *"سوريا: جامعة الشمل"*.
- **الأهداف الاستراتيجية الثمانية**: ترسيخ نهج محوره الإنسان، تعزيز الفخر الوطني، الارتقاء بالصورة الدولية، والتحول الرقمي، مع ترجمة كاملة باللغة الإنجليزية.
- **لماذا احتاجت سوريا إلى هوية جديدة؟**: مقارنة التشويه السابق بالهوية الوطنية الحرة الشاملة.
- **الشرائح المستهدفة الـ 6**: السوريون في الداخل والمهجر، السياح، المستثمرون، والمنظمات الدولية.
- **سمات نبرة الصوت**: واثقة، ملهمة، دافئة، متقدمة، ومتناغمة بجميع اللغات.

### 3. عناصر الهوية البصرية (Brand Elements)
- **تشريح الشعار ومعاني الرموز**: النجمة الثمانية، القلب في المركز، وتلاقي المسارات باللغتين العربية والإنجليزية.
- **لوحة الألوان الرسمية (Color Palettes)**:
  - الأخضر الغابي (*Forest*): `#428177`, `#054239`, `#002623`
  - القمح الذهبي (*Golden Wheat*): `#edebe0`, `#b9a779`, `#988561`
  - العنبري الدمشقي (*Deep Umber*): `#6b1f2a`, `#4a151e`, `#260f14`
  - الفحمي والأبيض (*Charcoal*): `#ffffff`, `#3d3a3b`, `#161616`
  - دعم النسخ الفوري لقيم الألوان بصيغ: `HEX`, `RGB`, `CMYK`, `OKLCH`.
- **الزخارف والأنماط التراثية**: مستوحاة من العمارة والفنون السورية مع ميزة المعاينة بالحجم الكامل وعناوين ثنائية اللغة.
- **تطبيقات الهوية في الواقع**: معرض لنماذج جواز السفر والوثائق الدبلوماسية، الصروح الحكومية، البدلات والمراسم، واللوحات الحضرية.

### 4. الأدوات والرموز الوطنية (Tools & Digital Assets)
- **العلم السوري ونسبه الهندسية الدقيقة**:
  - مخطط تفاعلي دقيق لنسب الطول والعرض (36:24 أو 3:2) وتوزيع النجوم الحمراء الخماسية الثلاثة (25%, 50%, 75%) مع مؤشرات هندسية ثنائية اللغة.
  - تحميل ملفات المتجهات الرسمية (`SVG`, `PNG`, `AutoCAD DWG`).
  - تحميل الدليل الإرشادي للعلم السوري (PDF - إعداد المصمم عبدالرحمن حداد).
- **مختبر تجربة الخط والتايبوغرافي**:
  - معلومات وترخيص **خط قمرة (Qomra)** الرسمي من وكالة iWantype.
  - دعم وتضمين خط **حيّاكم الله (Hayyakum Allah)** المجاني بأربعة أوزان (Light, Regular, Medium, Bold) مع بطاقات أوزان مترجمة.
  - حقل كتابة تفاعلي مباشر لتجربة الخطوط بأوزان وأحجام مختلفة بنصوص تجريبية تتكيف مع اللغة النشطة.
- **أيقونات المحافظات السورية الـ 14**:
  - إعداد وتصميم الفنانة **ولاء** (`@walaa_akdesign`).
  - معالم المحافظات: دمشق (السيف الدمشقي)، ريف دمشق (الغوطة)، حلب (القلعة)، حمص (الساعة)، حماة (النواعير)، اللاذقية (قوس النصر)، طرطوس (جزيرة أرواد)، إدلب (رويحة)، دير الزور (الجسر المعلق)، الرقة (بوابة بغداد)، الحسكة (جسر عين ديوار)، درعا (المسجد العمري)، السويداء (قنوات)، القنيطرة (بيت صيدا).
  - تبديل حي وديناميكي فوري للألوان عبر 5 لوحات معتمدة (كلاسيكي، غابي، قمح ذهبي، عنبري دمشقي، فحمي داكن) مع عزل أسماء فئات CSS لكل رمز لتفادي أي تداخل.
  - تنزيل مباشر لملفات المتجهات `SVG` الملوّنة وفق اللوحة المختارة.
- **خريطة سوريا الرقمية التفاعلية**:
  - مبنية على حدود `GeoJSON` دقيقة تم تحويلها إلى متجهات SVG خفيفة وسريعة.
  - تحديد وتلوين المحافظات بالنقر والبحث واستعراض المعلومات والمعالم.

### 6. المستودع الرقمي للتحميل والمعاينة (Downloads Vault & Lightbox)
- **معاينة وتحميل وثيقة التصميم ([DESIGN.md](./DESIGN.md)) مباشرة من المتصفح**: نافذة تفاعلية مدمجة تتيح قراءة الدليل كاملاً بتنسيق منسق، أو بنظام الكود الخام (Raw Code)، مع بحث نصي سريع، ونسخ كامل للحافظة بضغطة زر، وتنزيل ملف `.md` مباشرة دون مغادرة الموقع.
- **المعاينة البصرية المسبقة**: عرض صور حيّة لجميع الشعارات والمتجهات ومخططات العلم والزخارف قبل تنزيلها مع وسوم ثنائية اللغة (`tagAr` / `tagEn`).
- **نافذة المعاينة المكبرة (Lightbox Modal)**: ميزة فحص كل أصل بدقة عالية مع إمكانية تبديل لون الخلفية ونسخ رابط التحميل أو التنزيل المباشر.
- **الحزمة الرسمية الشاملة**: ملف مضغوط `Syrian_Identity_Official_Package.zip` بحجم 4.5 ميغابايت يضم 125 ملفاً أصلياً بصيغ `SVG`, `PDF`, `EPS`, `PNG`.
- **أزرار النسخ للذكاء الاصطناعي (Copy for AI)**: زر مخصص بجانب كل أصل لنسخ وسوم الـ HTML/Markdown المهيأة للإدراج الفوري في برومبتات الذكاء الاصطناعي.

### 7. الدليل الإرشادي وبوابة المطورين (DESIGN.md & AI Dev Hub)
- **المعاينة والتحميل الفوري لـ DESIGN.md**: فتح واستعراض وثيقة التصميم الشاملة بضغطة زر داخل واجهة الذكاء الاصطناعي.
- **بنك أوامر الذكاء الاصطناعي (AI Prompt Cookbook)**: أوامر متطابقة ثنائية اللغة (عربي وإنجليزي) مصممة للإلصاق المباشر في نماذج الذكاء الاصطناعي (Cursor, ChatGPT, Claude) لإنشاء مكونات متوافقة هندسياً ولونياً.
- **دليل `llms.txt` و `llms-full.txt`**: مواصفة معيارية لمساعدة وكلاء الذكاء الاصطناعي.
- **رموز التصميم القياسية (Design Tokens)**: ملفات `tokens.css`, `syria-preset.js`, و `tokens.json`.
- **قواعد الوكلاء البرمجية (Agent Rulesets)**: ملفات `.cursorrules`, `CLAUDE.md`, و `.github/copilot-instructions.md`.
- **معيار WebMCP (Web Model Context Protocol)**: استكشاف قياسي عبر `/mcp.json` و `/.well-known/mcp.json`.

### 8. تحسين محركات البحث والظهور العالمي (SEO & Metadata)
- **بيانات وصفية شاملة ثنائية اللغة**: عناوين، كلمات مفتاحية استراتيجية تغطي كافة مسميات الهوية السورية، والأعلام والشعارات.
- **Schema.org JSON-LD**: بطاقات منظمة لنوع `WebSite`، `CreativeWork`، و `Organization`.
- **بطاقات التواصل الاجتماعي**: Open Graph و Twitter Cards بدعم لغات متعددة (`ar_SY`, `en_US`).
- **خريطة الموقع وملف الزواحف**: ملف `sitemap.xml` و `robots.txt` يتيح فهرسة كاملة لجميع الأقسام ووثائق التصميم.

## 🛠 التقنيات المستخدمة (Tech Stack)

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler**: [Vite 5](https://vitejs.dev/) (مع ضبط `base: './'` لدعم GitHub Pages على أي مسار)
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com/) + خطوط عربية مدمجة
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [GitHub Pages](https://pages.github.com/) عبر GitHub Actions Workflow

## 🚀 التشغيل والتطوير المحلي (Local Development)

1. **تثبيت الاعتماديات**:
```bash
npm install
```

2. **تشغيل خادم التطوير المحلي**:
```bash
npm run dev
```

3. **بناء النسخة الإنتاجية**:
```bash
npm run build
```

4. **معاينة البناء الإنتاجي**:
```bash
npm run preview
```

## 📦 النشر على GitHub Pages

المشروع مزود مسبقاً بملف سير عمل تلقائي `.github/workflows/deploy.yml`:
1. ارفع المشروع إلى مستودع GitHub:
   ```bash
   git remote add origin https://github.com/sytocode/syrian-visual-identity.git
   git branch -M main
   git push -u origin main
   ```
2. من إعدادات المستودع (Settings) -> انتقل إلى **Pages**.
3. في قسم **Build and deployment**، اختر **Source**: **GitHub Actions**.
4. عند كل عملية `git push` لفرع `main`، سيتم بناء الموقع ونشره تلقائياً على الرابط العام:
   `https://sytocode.github.io/syrian-visual-identity/`
