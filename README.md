# الهوية البصرية - الجمهورية العربية السورية | Syrian Visual Identity

موقع ويب توثيقي وتفاعلي متكامل يُعيد إحياء وحفظ **الهوية البصرية الرسمية للجمهورية العربية السورية** بعد توقف موقعها الرسمي، مدمجاً بكافة الأدوات الرقمية والموارد التصميمية من بوابة **Syrian Zone**.

المشروع مصمم ليكون تطبيق ويب ثابت (Static Web App) فائق السرعة والأناقة، متوافق بنسبة 100% مع النشر المباشر على **GitHub Pages**، ومزود بدعم ثنائي اللغة (العربية بالاتجاه الطبيعي RTL والإنجليزية LTR)، والوضع الليلي/النهاري، مع الحفظ التلقائي لتفضيلات اللغة والمظهر في المتصفح (LocalStorage).

---

## 🌟 المحتويات والأقسام الرئيسية

### 1. الرئيسية (Home)
- **واجهة بصرية غنية**: تصميم ترحيبي مهيب يجمع بين شعار *"انتماءٌ راسخ يتجاوز الحدود"*، ورمز الختم الوطني المضيء، ونقش زخرفي نجمي دقيق.
- **شريط المؤشرات الوطنية**: 14 محافظة سورية موحدة، 4000+ عام من الحضارة، 125 أصلاً رسمياً، وتوثيق مجاني 100%.
- **معرض الأنماط والزخارف التراثية (Heritage Patterns)**: استعراض تفاعلي للأنماط الهندسية الأربعة المستوحاة من العمارة الأموية، التناظر النجمي الدمشقي، وتسنيم قلاع حلب.
- **تطبيقات الهوية في الحياة (Real-World Gallery)**: شبكة بصرية متكاملة (Bento Grid) لنماذج الهوية في المعارض، المستندات الدبلوماسية، الأوشحة الدمشقية، اللافتات الحضرية، وتغليف المنتجات.
- **شريط رموز المحافظات**: عرض مباشر لمعالم المحافظات السورية بتقنية SVG مع روابط سريعة للخريطة التفاعلية.
- **المبادئ الفلسفية للعلامة**: بطاقات معمقة لـ *"سوريا هي القلب"* و*"قصتنا إلى العالم"*.

### 2. قصة الهوية والرسالة (Brand Story)
- **الرؤية والرسالة والتموضع الوطني**: *"سوريا: جامعة الشمل"*.
- **الأهداف الاستراتيجية الثمانية**: ترسيخ نهج محوره الإنسان، تعزيز الفخر الوطني، الارتقاء بالصورة الدولية، والتحول الرقمي.
- **لماذا احتاجت سوريا إلى هوية جديدة؟**: مقارنة التشويه السابق بالهوية الوطنية الحرة.
- **الشرائح المستهدفة الـ 6**: السوريون في الداخل والمهجر، السياح، المستثمرون، والمنظمات الدولية.
- **سمات نبرة الصوت**: واثقة، ملهمة، دافئة، متقدمة، ومتناغمة.

### 3. عناصر الهوية البصرية (Brand Elements)
- **تشريح الشعار ومعاني الرموز**: النجمة الثمانية، القلب في المركز، وتلاقي المسارات.
- **لوحة الألوان الرسمية (Color Palettes)**:
  - الأخضر الغابي (*Forest*): `#428177`, `#054239`, `#002623`
  - القمح الذهبي (*Golden Wheat*): `#edebe0`, `#b9a779`, `#988561`
  - العنبري الدمشقي (*Deep Umber*): `#6b1f2a`, `#4a151e`, `#260f14`
  - الفحمي والأبيض (*Charcoal*): `#ffffff`, `#3d3a3b`, `#161616`
  - دعم النسخ الفوري لقيم الألوان بصيغ: `HEX`, `RGB`, `CMYK`, `OKLCH`.
- **الزخارف والأنماط التراثية**: مستوحاة من العمارة والفنون السورية مع ميزة المعاينة بالحجم الكامل.
- **تطبيقات الهوية في الواقع**: معرض لنماذج المطبوعات الرسمية، الأوشحة، اللافتات الحضرية، وتصميم الواجهات.

### 4. الأدوات والرموز الوطنية (Tools & Digital Assets)
- **العلم السوري ونسبه الهندسية الدقيقة**:
  - مخطط تفاعلي دقيق لنسب الطول والعرض (36:24 أو 3:2) وتوزيع النجوم الحمراء الخماسية الثلاثة (25%, 50%, 75%).
  - تحميل ملفات المتجهات الرسمية (`SVG`, `PNG`, `AutoCAD DWG`).
  - تحميل الدليل الإرشادي للعلم السوري (PDF - إعداد المصمم عبدالرحمن حداد).
- **مختبر تجربة الخط والتايبوغرافي**:
  - معلومات وترخيص **خط قمرة (Qomra)** الرسمي من وكالة iWantype.
  - دعم وتضمين خط **حيّاكم الله (Hayyakum Allah)** المجاني بأربعة أوزان (Light, Regular, Medium, Bold).
  - حقل كتابة تفاعلي مباشر لتجربة الخطوط بأوزان وأحجام مختلفة.
- **أيقونات المحافظات السورية الـ 14**:
  - إعداد وتصميم الفنانة **ولاء** (`@walaa_akdesign`).
  - معالم المحافظات: دمشق (السيف الدمشقي)، ريف دمشق (الغوطة)، حلب (القلعة)، حمص (الساعة)، حماة (النواعير)، اللاذقية (قوس النصر)، طرطوس (جزيرة أرواد)، إدلب (رويحة)، دير الزور (الجسر المعلق)، الرقة (بوابة بغداد)، الحسكة (جسر عين ديوار)، درعا (المسجد العمري)، السويداء (قنوات)، القنيطرة (بيت صيدا).
  - ميزة التبديل الحي لألوان الأيقونات وتنزيلها بصيغة `SVG` مدمجة ومباشرة دون أي أخطاء 404.
- **خريطة سوريا الرقمية التفاعلية**:
  - مبنية على حدود `GeoJSON` دقيقة تم تحويلها إلى متجهات SVG خفيفة وسريعة.
  - تحديد وتلوين المحافظات بالنقر والبحث واستعراض المعلومات والمعالم.

### 6. المستودع الرقمي للتحميل والمعاينة (Downloads Vault & Lightbox)
- **المعاينة البصرية المسبقة**: عرض صور حيّة لجميع الشعارات والمتجهات ومخططات العلم والزخارف قبل تنزيلها، مع خلفيات متباينة ذكية (خلفيات داكنة للشعارات البيضاء، وخلفيات فاتحة للشعارات الخضراء والداكنة).
- **نافذة المعاينة المكبرة (Lightbox Modal)**: ميزة فحص كل أصل بدقة عالية مع إمكانية تبديل لون الخلفية (شبكة شفافة، داكنة، خضراء زمردية، أو فاتحة) ونسخ رابط التحميل أو التنزيل المباشر.
- **تبويبات التصفية السريعة**: تصفية الأصول حسب الفئة (كافة الأصول، الشعارات والرموز، مخططات العلم، الأنماط التراثية).
- **الحزمة الرسمية الشاملة**: ملف مضغوط `Syrian_Identity_Official_Package.zip` بحجم 4.5 ميغابايت يضم 125 ملفاً أصلياً بصيغ `SVG`, `PDF`, `EPS`, `PNG`.
- **أزرار النسخ للذكاء الاصطناعي (Copy for AI)**: زر مخصص بجانب كل أصل لنسخ وسوم الـ HTML/Markdown المهيأة للإدراج الفوري في برومبتات الذكاء الاصطناعي.

### 7. الدليل الإرشادي الشامل وبوابة المطورين (DESIGN.md & AI Dev Hub)
- **دليل التصميم الشامل ([DESIGN.md](./DESIGN.md))**:
  - وثيقة معمارية شاملة تضم فلسفة الهوية، هندسة ومقاسات الشعار، قواعد العلم الدستوري، مصفوفة الألوان الكاملة ومستويات التباين، التايبوغرافي والخطوط، والرموز المعمارية للمحافظات الـ 14.
- **دليل `llms.txt` و `llms-full.txt`**: مواصفة معيارية في جذر الموقع تُلخص فلسفة الهوية، الروابط المباشرة للمتجهات، معادلات الألوان، وهندسة العلم الدستوري للذكاء الاصطناعي.
- **رموز التصميم القياسية (Design Tokens)**:
  - ملف `tokens.css`: متغيرات CSS قياسية وفئات مساعدة جاهزة (`.bg-syria-forest`, `.border-syria-gold`, إلخ).
  - ملف `syria-preset.js`: ملحق جاهز لـ Tailwind CSS يمكن استيراده مباشرة في `tailwind.config.js`.
  - ملف `tokens.json`: مواصفة قياسية بصيغة DTCG (Design Tokens Community Group).
- **قواعد الوكلاء البرمجية (Agent Rulesets)**:
  - ملف `.cursorrules` لمحرر Cursor.
  - ملف `CLAUDE.md` لأداة Claude Code و Anthropic.
  - ملف `.github/copilot-instructions.md` لـ GitHub Copilot.
- **معيار WebMCP (Web Model Context Protocol)**:
  - استكشاف قياسي عبر `/mcp.json` و `/.well-known/mcp.json`.
  - تسجيل المتصفح التلقائي على `navigator.modelContext` وكائن `window.syrianIdentityMCP`.
- **بنك أوامر الذكاء الاصطناعي (AI Prompt Cookbook)**: أوامر مدروسة بعناية لنسخها ولصقها في محادثات الذكاء الاصطناعي لإنشاء ترويسات ومكونات وعلم سوريا المتجاوب.

## 🛠 التقنيات المستخدمة (Tech Stack)

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler**: [Vite 5](https://vitejs.dev/) (مع ضبط `base: './'` لدعم GitHub Pages على أي مسار)
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com/) + خطوط عربية مدمجة
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [GitHub Pages](https://pages.github.com/) عبر GitHub Actions Workflow

## 🚀 التشغيل والتطوير المحلي (Local Development)

1. **تثبيت الاعتماديات**:
```bash
npm install
```

2. **تشغيل خادم التطوير المحلي**:
```bash
npm run dev
```

3. **بناء النسخة الإنتاجية**:
```bash
npm run build
```

4. **معاينة البناء الإنتاجي**:
```bash
npm run preview
```

## 📦 النشر على GitHub Pages

المشروع مزود مسبقاً بملف سير عمل تلقائي `.github/workflows/deploy.yml`:
1. ارفع المشروع إلى مستودع GitHub:
   ```bash
   git remote add origin https://github.com/sytocode/syrian-visual-identity.git
   git branch -M main
   git push -u origin main
   ```
2. من إعدادات المستودع (Settings) -> انتقل إلى **Pages**.
3. في قسم **Build and deployment**، اختر **Source**: **GitHub Actions**.
4. عند كل عملية `git push` لفرع `main`، سيتم بناء الموقع ونشره تلقائياً على الرابط العام:
   `https://sytocode.github.io/syrian-visual-identity/`
